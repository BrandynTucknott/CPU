```
8-bit
├── src	    # Verilog source files
├── tb	    # testbenches
├── sim	    # simulation output (such as waveform dumps and logs)
├── docs    # diagrams, design notes, architecture writeups
└── logism  # .circ file to view via Logism-Evolution
```
The files in the ```logism``` directory are ```.circ``` files which can be opened and viewed via Logism-Evolution,
an open source educational software for building and interacting with digital logic circuits. This is where
much of the prototyping took place (so far, may change in the future).

Logism-Evolution can be found here: https://github.com/logisim-evolution/logisim-evolution
